### Featured work

**[StudEd](https://github.com/Gehan-malshan/studed-project)**  
A cloud-native learning platform built as a team project with Go services, a GraphQL gateway, gRPC, Kubernetes, and GitOps. My work includes an upload service, container builds, infrastructure changes, and distributed tracing.
